With signed links you **don't need a bucket policy at all**. Delete it and leave the bucket policy empty. Access comes from the IAM user's permissions, not the bucket.

That error means the `Resource` doesn't match the actions. `s3:GetObject` and `s3:PutObject` act on **objects**, so the ARN has to end in `/*`:

- ❌ `arn:aws:s3:::my-bucket`: this is the bucket itself, and object actions don't apply to it, which causes your error
- ✅ `arn:aws:s3:::my-bucket/*`: this means every object inside the bucket

The same thing happens if the bucket name in the ARN has a typo, or if you pasted `YOUR-BUCKET-NAME` literally.

**Where the permissions go:** IAM → Users → `fathom-clone-app` → Permissions → Add permissions → Create inline policy → JSON tab. Paste this, replacing `my-bucket` with your exact bucket name:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["s3:PutObject", "s3:GetObject"],
      "Resource": "arn:aws:s3:::my-bucket/*"
    }
  ]
}
```

On the bucket itself:
- **Block all public access:** leave it ON
- **Bucket policy:** leave it empty
- **CORS:** yes, add the JSON from before
